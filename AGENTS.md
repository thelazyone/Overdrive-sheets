# Overdrive project context

Before changing Overdrive rules, ships, systems, Charter progression, or balance tools, read `OVERDRIVE.md` in this repository. It is the shared ownership map and design brief for both Overdrive repositories.

The companion game and alpha rules are in `../overdrive-sandbox`. Inspect relevant companion sources before changing shared concepts. Keep canonical authoring data here; do not treat the combinator's sample data or sandbox fixtures as the master roster. Follow the change checklist in `OVERDRIVE.md` and report any consumers left out of sync.
